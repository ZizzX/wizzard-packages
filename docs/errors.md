# Errors

Every code the library reports has its own page on the documentation site, at
`https://zizzx.github.io/wizzard-packages/errors/<code>`, written from
`site/src/content/docs/errors/<code>.md`.

This file stays because releases published before the pages moved end their messages in a link
to a heading here. Each heading below is one of those codes and points at its page; the text
lives only in the page, so the two cannot drift. New codes get a page and no heading.
